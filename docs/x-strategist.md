## v4改訂の根拠（overview CSV 5/2〜7/30 日次 + 417投稿CSV）

### v3.2の誤診を訂正する

v3.2は投稿カード帰属のフォロー数（11件）だけを見て「訪問483→フォロー11＝転換率2.3%が主犯」とした。アカウント全体の日次データでは:

| 指標 | 実測（5/2〜7/30・13週） |
|:--|:--|
| フォロー獲得（グロス） | **71人**（投稿帰属は11人だけ。85%はリプ・検索・おすすめ経由でプロフィールから直接） |
| フォロー解除 | 34人 |
| 純増 | +37人 = **+2.8人/週** |
| プロフ訪問 | 427（**4.7人/日**） |
| imp→訪問 | 0.38% |
| 訪問→フォロー | **16.6%** |

訪問→フォロー16.6%は壊れていない。**壊れているのは訪問の絶対数。** ボトルネックは「新規オーディエンスとの接触イベントの数」。

### 接触イベントを生むのは中央値ではなくヒットと他人のスレッド

- オリジナル361本中、500imp超は32本（9%）。**この9%が全プロフ訪問の46%を生んだ**（訪問上位5本だけで20%）
- 中央値150〜200の投稿はフォロワー1,183人の約1割に届いて終わり。非フォロワーに届くのはヒット時と他人のスレッド内だけ
- 引用RT（7字）が2,920imp。他人の文脈に乗った時のリーチは自前中央値の20倍
- **中央値impの最適化は成長に効かない指標の最適化だった。** ヒット試行数と絡み実行数を最適化する

### 戦略と実行の乖離が本丸だった

v3は「時間配分の5割は絡み」と書き、ルーティンは毎枠5件・1日15枚の絡み候補をSlackに届けていたが、実行された絡みは90日で5本。カードが多すぎ・コピペ即投稿の形になっておらず・実行数を誰も計測していなかった。v4はカードを1日3枚に絞り、完成文形式にし、実行数を週次KPIにする。

## E1: 投稿エンジン（縮小・質のフロア引き上げ）

投稿の目的は2つだけ: **(1)ヒット試行 (2)プロフィールに来た人が見る壁の品質維持**。フォロワー獲得の主戦場は投稿ではなく絡みとプロフィール。

### 起点の反転（v4.2・最重要）

書き始めるのは「ニュースに何が書いてあるか」ではなく**「このニュースで読者（下請け・工務店の社長）の仕事・金・工期に何が起きるか」**。

- ✕ 「2025年度の住宅着工は71万戸で最低。単月の読み方に注意」→ ニュースの要約に解釈を付けた社説。正確だが感情が動かない
- ◯ 「住宅の仕事、減ってるどころの話じゃなかった」→ 読者の損得が主語。同じ数字が物語になる
- どれだけ大きいニュースでも、読者の感情を動かす形に変換できなければ使わない

### 本数と休載ルール（v4.1で修正）

- 下書きは基本毎枠出す（0〜3本/日）。**休載基準（v4.2改訂）: 感情ゲートを通るネタが見つからない時は休む**。おもろくない下書きは新田さんのリライト時間を奪うだけ。ただし休載判定の前に最低5ネタ探索し、危機直撃・暴露・通説反論に変換できないか粘る（「新情報が弱い」だけの休載は引き続きNG）
- 字数の目安: 朝=フル尺(250〜300字) / 昼・夜=140〜220字。**枠×型の固定（朝A/昼B/夜C）は廃止**。勝ち型4種から、その日一番感情が動くネタを使う
- 実際に何本世に出るかは新田さんのリライト次第。**週5本以上の投稿を目安**にする（下回る週が続いたら週次分析が指摘）

### 必須要素ゲート（全オリジナル投稿・1つでも欠けたら没）

0. **感情ゲート（v4.2・最上位）**: 読み終わった読者の感情が1個動くか。**やべえ**（危機が自分に来る）/ **マジか・そこ言う？**（暴露・意外）/ **いや違う**（通説反論）のどれかを、下書きを書く前に一言で言えること。言えないネタは実名・数字が揃っていても没
1. **実名を1つ以上**: 企業名 / 制度名 / 省庁名 / 統計名（出典が言える実データ）
2. **数字を2つ以上**: %・円・件数・人数・日付など
3. **新情報が1つ以上**: 読者がブックマークか引用したくなる、まだ皆が知らない事実
4. **現場への含意を1行**: この数字が中小の建設会社の明日にどう効くか（格言・標語ではなく具体）
5. **一人称の一次観点を1文以上**: 新田本人の判断・解釈・違和感を地の文で書く

### ゲート5の運用（v4.1で人間側工程に移管）

7/28〜30の9本が全部「〜と僕は見てる」「〜と僕は思う」の同型2連で締めていた。型化したゲート5はニュースbotの新しい皮になるだけ。**結論: 機械が一人称を書くのをやめた。**

- 下書き（機械）: ゲート1〜4のみ。一人称は書かず、`hint` に解釈の種2〜3個を渡す
- リライト（新田さん）: 自分の言葉で判断・解釈・違和感を入れる。これがゲート5の実体。長さも言い回しも自由（下書きの構成を崩してよい）
- ✕ 創作した商談・訪問・会話（実際に起きたことだけ）/ ✕ 伝聞ヘッジ / ✕ コンサル一般論への着地 — はリライト後も守る

### 勝ち型4種（v4.2・ヒット実測から再定義）

跳ねた投稿は全部この4型のどれかだった。旧A型「ニュース解剖」・旧B型「データ解釈」のような**正確な解説は型から外す**（ニュース・統計は下の4型に変換できた時だけ使う）:

- **① 危機直撃型（やべえ）**: 読者の仕事・金・工期に来る危機を正面からデカく言う。倒産・値上げ・受注停止・仕事量の消失・納期遅延。実績: GW資材まとめ 4,247 / TOTO受注停止 2,222
- **② 暴露型（そこ言う？）**: 業界の裏側・みんな薄々気づいてるが誰も言わない構造。実績: 相見積に競争が最初からない 5,820（imp自己ベスト）
- **③ 通説反論型（いや違う）**: みんなが原因Aだと思ってる話の、本当の原因B。実績: 塗装業倒産は資材高騰じゃなく時間差の資金繰り 4,490・いいね70（いいね自己ベスト）
- **④ 一次体験型（マジか）**: 現場を何百件見てきた実感からの断言（実際の経験のみ・創作禁止）。実績: 施工計画書の解体手順ほぼ白紙 4,587

### 字数・文体（07-31改訂: 「機械っぽい」対策 / 08-03: 感情フック）

- **1行目は感情フック**（v4.2追加。機関名・統計名・「2025年度の〜は」から書き始めない。読者の損得か違和感で始めて、出典（機関名＋発表日）と数字は2行目以降で支える）
- **数字は2〜4個・主役1個**（07-31追加。新田さん指摘「数字入れすぎてもダメ」。数字の羅列は決算レポート調になる。一番意外な数字を立てて残りは捨てる）
- **報告書・ニュース原稿調の禁止**（07-31追加。「〜と発表した」「〜となった」をやめ、下の参考文体=新田さん自身の投稿のリズムに寄せる。文は短く、話すように）
- 100〜300字（推奨140〜220）。1ブロック・空行禁止・**文ごとに改行必須**（本文3〜6行。改行ゼロの壁テキストは没）
- 冒頭パターンの強制なし。直近5投稿と同じ書き出し構文は避ける
- ハッシュタグ禁止 / URLは本文もリプも禁止（出典は「機関名＋発表日」を本文に）/ DM誘導禁止 / 自社宣伝は本文禁止
- AI臭ワード辞書（しきい値2）:
  - 語尾NG: 〜になる / 〜になってる / 〜が大きい / 〜のが効く / 〜という構造 / 〜という流れ / 〜という話 / 〜が見えてくる / 〜が浮かび上がる / 〜が問われる / 〜になり始めてる / 〜が広がってる
  - 接続NG: ただ、/ 一方で、/ 結局、/ 要は、/ つまり、/ 正直、/ 実は、/ ちなみに、/ しかし、（「でも」「だから」「やっぱり」はOK）
  - 記号NG: 全角ダッシュ、カギカッコ連発
- 極論・断定・煽り禁止。「お前」禁止。「人を送ってる」禁止。「地味にすごい」禁止

### 画像（08-03改訂: 記事スクショ式）

- **第一候補は元記事のスクショ**（いしおくん @Stoneman_ISHIO 式）: 記事の見出し・図表部分のスクショを画像添付する。リンクペナルティ（リンク付きimp中央50 vs 無し183）を受けずに、記事の信頼感とタイムラインでの面積を取れる。ルーティンは `article_url` にスクショ用記事を1本指定し、撮影・添付は新田さんがリライト時に行う
- Gemini生成の表画像は実測で効いていない（画像あり中央値135 vs 無し186・ヒット投稿は全部文字のみ）→ 本文にない数字を可視化できる時だけの第二候補に降格
- スクショは見出し・リード中心（記事全文のスクショはしない）。出典の機関名＋発表日は本文に書く運用を継続

### マンネリ対策（維持）

- 同一の具体的事実・同一の数字×固有名詞ペアの再利用を14日間ban（ジャンルbanはしない。新事実が出れば同ジャンル毎週OK）
- 書き出し構文の被り（直近5投稿）もチェック

### 自己リプ全廃（維持）

`add_post` に `reply_text` を渡さない。ソースURLはdashboard.jsonの `source_url` に残すだけ（投稿しない）。

## E2: 絡みエンジン（最重要・実行率を直す）

インプ上位は大アカへの早いリプと引用RTが独占する。オリジナルより絡みのほうがフォロワー圏外に届く。**v4の最優先はカードの生成品質ではなく実行率。**

### カードは1日10枚目安（各枠3〜4枚・07-31 新田さん要望で増枠）

- v4当初は「実行されない前提」で1日3枚に絞ったが、リライト運転で新田さんが手動投稿にコミットしたため10枚目安に増枠（2026-07-31）

2. **建設業界に直接関連する内容**（業界外はどれだけバズってても除外）
3. **いいね50以上 or 投稿者フォロワー2,000以上**（小アカリプはインプ0〜30で無駄打ち）

### 計測ルール（重要・v3.2の誤診の再発防止）

- **投稿カード帰属のフォロー数をファネルの分母・分子に使わない**（実フォローの85%は投稿外経由。content CSVのフォロー列は参考値扱い）

### KPI
