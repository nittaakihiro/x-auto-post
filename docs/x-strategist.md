## 柱は3本
1. **作ってみた**（週2〜3本・本人とローカルの Claude Code で制作。ルーティンは作らない）
   建設の業務をAIにやらせたデモ動画。「Claude Opus5.5 × ○○」「作ってみた」「やらせてみた」で出す。製品発表・リリース・受託案件としては出さない（「リリースしました」「できるようにしました」「サービス化」は書かない）。客先名・客先図面は出さない。図面は実務密度の自社作図か公開図面。
2. **国内外の建設AIのすげーニュース**（ルーティンで毎日2本＝昼・夜。動く素材が必須。v7.3で国内も対象）
   国内・海外は問わず、直近48hで一番すげーものを選ぶ。ロボット、自律で動く重機、3Dプリント住宅、BIM/CADを操作するAI、ドローン測量、現場の自動化など、映像を見て驚くもの。解説記事・調査レポート・市場予測・「〜の6つの領域」のような記事は採用しない。資金調達・出資・買収・合弁・提携のニュースも、金額が大きくても絵がないので採用しない（10-01 本人「面白くない」）。機械やAIが実際に動いている映像があり、何をしているか1秒で分かるものだけ。**投稿に付ける動画（video_url）が取れないネタは、記事に映像があっても採用しない**。個人が作ってみたもののバズ（例：コードを書かずに作った設計ツール）も国内外とも対象。国内ネタはゼネコン・メーカー・研究機関の公式発表や公式X・YouTubeの映像、建設系アカウントの動画付き投稿から拾う。

3. **本質投稿**（夕枠・文字だけの投稿はこれだけ。10-03 本人「芯をくっている本質投稿にしてほしい」）
   建設業とAI・人手不足について、多くの人がうっすら感じているのに言葉にできていないことを、仕組みから言い当てる投稿。旧柱3（AIインフルエンサーのバズ投稿の建設版）は廃止。チャエン等の投稿は口調・段落の参考までにして、論旨は借りない。
   - **1投稿1主張**。主張は1行目に言い切る（〜だと思う、までは可。〜な気がする、は不可）
   - **なぜそうなるかを仕組みで書く**。題材にする仕組みの例：時間や人月で請求する値付け／元請けと専門工事会社の多重構造／発注者が求める書類の量／属人化と技術の継承／工期と天候／施工管理の残業と人手不足／ITの導入費を誰が持つか
   - **具体を1つ入れる**。公開された数字・時事・現場で実際に起きること（工種・書類名・工程名まで）。新田さんの体験・社内の数字は創作しない（本人が話した内容か、公開済みのものだけ）
   - **読んだ建設会社の社長や現場の人が、明日の判断を1つ変えられる**ところで終える
   - 素材の取り方：建設時事（過去のimp1,000超は3本とも建設時事＋当事者の見立て＝竹中背任2,883／最低賃金2,674／元請倒産1,783）、国内外のAIニュースが建設業の仕組みのどこに効くか、建設の数字（国交省・建設経済研究所・帝国データバンク等の公表値）
   - 自社サービス名は出さない。NITACOの考え（専門業務を人の時間ではなくAIと専門家のチェックで売る、等）を視点として使うのは可

   **不採用の書き方**（10-02〜03の下書きより）：
   - 〜が再評価されてる気がする／鍵はA×B×Cかなと／もちろん〜も大事（両論併記で主張が消える）
   - AIを使えば誰でも6〜7割は出せる、のような根拠のない数字
   - チャットを役割ごとに分けるとうまくいく、のような建設でなくても言えるTips
   - 判定：チャエンや一般のAIアカウントが同じ文を書けるなら不採用。建設業の仕組みを知らないと書けない一文が無ければ不採用

   **見本**（型の例。数字は使う時に必ず裏取りする）
```
建設業でAIが広がらない一番の理由は、技術じゃなくて値付けだと思います。

人の時間で請求している仕事は、AIで作業が半分になると売上も半分になる。
だから業務を受けている側ほど、AIを入れる理由がない。

積算も書類作成も、見積もりの単位が人工や時間のままなら、効率化はそのまま値下げになります。

先に変わるのは、時間ではなく出来上がったもので値段をつけた会社からです。
```

一般AIの速報（朝）は脇役として残す。

**v7.2（10-05 本人）**：「結局現場で使えるAI技を動画にすること、最新ニュースでこういう使い方できるとか、そういうのが伸びる」。全枠に次の5つを適用する。
- **現場でこう使える**：ニュースは紹介で終わらせない。建設の誰が・どの作業で・明日どう使えるかまで書く（例：ホテル設備の3D化 → 施主説明・新人教育に使える／物流の自動リルート → 生コン車の遅れに使える）
- **タグは原則なし**：【速報】【注目】【朗報】などは、誰もが驚く規模の発表（主要AI企業の新モデル・大手の大型発表クラス）の時だけ。迷ったら付けない。1行目は見出しの1文から始める
- **英語の引用元には解説**：英語の投稿を引用・紹介する時は、本音の行のあとに「引用元は英語なので補足すると、〜という動画です」の段落を1つ入れる（誰が・何に・何をさせて・どうなったか）。元の本文と動画の内容から書き、書いていないことは足さない
- **結論は本人のポジションと噛み合わせる**：このアカウントは建設業にAIを入れる側の人。締めは「AIをこう使うと効く」「AIで浮いた時間をここに回した会社が先に行く」の向きにする。「AI導入より○○が先」のような、AIを後回しにする締めは不採用。書いたら、新田さんが言って違和感がないかを最後に確認する
- **入口は直近のニュース**：投稿のきっかけ（1行目・最初の段落）は直近48hの出来事にする。数か月前の制度決定や昨年度の統計は、補足の根拠には使ってよいが、入口にはしない（10-05 の夕枠で、2025年12月の労務費基準を入口にして不採用）

**v7.3（10-06 本人）**：「国内でも海外でも建設×AIネタは拾っておいてくれな」。
- 柱2を「海外の」から「国内外の」建設AIのすげーニュースに広げる。国内ネタ（ゼネコンのロボット・自動施工の実証、メーカーの新製品デモなど）も同じ基準（動く素材必須・直近48h・5観点）で候補に入れ、国内外を並べて一番すげーものを採る
- 国内ネタは日本語なので解説段落は不要。社名・数字は公式発表どおり
- **建設×フィジカルAIを重点ネタにする**（10-06 本人「建設×フィジカルAIネタもほしい」）。人型ロボット・四足歩行ロボット・ロボットアーム・自律で動く重機・ロボット向け基盤モデルが、現場の作業（溶接・鉄筋・内装・巡回・資材運搬・掘削など）を実際にやっている映像。国内外とも対象で、同点ならフィジカルAIを優先する。工場や家庭のロボットでも、建設の作業に置き換えられるなら夜枠の代替候補にしてよい（置き換え先を本文に書く）
- 競合除外はそのまま（国内の建設向けAI開発/導入支援・BPO・営業代行は不可。ゼネコン・メーカー・研究機関は競合に当たらない）

## 型（チャエン @masahirochaen のバズ投稿をそのまま使う）
09-21〜27 の本投稿67本（imp中央値2.2万）の上位はほぼ次の型。

### 速報型（朝・昼・夜）— 24万/18万/10万表示の型
```
【速報】Googleが「Googlebook」を発表、本日から予約開始

Chromebookでも普通のノートPCでもない、Gemini前提の新カテゴリという打ち出し。

・2.8K OLEDタッチディスプレイ搭載
・バッテリー14時間駆動
・キーボードに専用のGeminiキー
・Androidスマホとシームレス連携、製造はHP

「今日は何を作る?」と話しかけて壁紙をその場で生成するデモ付き
↓詳細
```
1. 1行目：主語＋何をしたか。社名と製品名を入れる。【速報】などのタグは v7.2 のとおり、本当に大きな発表の時だけ
2. 1〜2行の本音（英語の引用元なら、このあとに解説の段落）：「普通に欲しい」「これは嬉しすぎる」「現場で普通に使えそう」「これは待ってた人めちゃくちゃ多いはず」など短く素直に
3. ・箇条を3〜4つ。数字（何秒・何%・何台・何m²）を入れる
4. 締めは「↓詳細」
5. 動画を付ける（video_url）。自己リプに「■ 補足」（箇条で背景・条件）と「■ 出典」（URL）
200〜300字（英語の解説を入れる場合は350字まで）。建設の誰がどの作業でどう使えるかを、本文に1〜2行入れる（補足に逃がさない）。

### 作ってみた型 — ブクマ最多（577）の型
```
Opus 5.5でアニメも作れる、、、　これは結構使えるかも。

海外で話題になっていた「全フレームをJavaScriptで描画するアニメ」を、Claude Code × Opus 5.5で日本語版にしてみました。
（箇条4つ：何をやったか・どこまでAIか）
今回はcanvasで1,395フレームを描画してmp4化。レンダリングも約2分でした。
（使い道1行）
（一言）
```
1行目に驚きの一言（「Opus 5.5で○○もできる、、、」）→ 何を渡して何をさせたか → 箇条4つ → 作業の実数（図面の枚数・室数・時間）→ 使い道 → 一言。250〜380字。

### 本質型（夕・文字だけ）
1行目に主張を言い切る → 2〜3段落で仕組み（なぜそうなるか）→ 具体を1つ → 最後の1段落で、だから何が変わるか・誰が先に動くか。150〜300字。箇条はなるべく使わない（使うなら仕組みの分解に限る）。【速報】などのタグ・↓詳細・画像は付けない。口調はです・ます基調で、感想語（すごい・嬉しい）は使わない。締めの決まり文句（〜かなと／〜が鍵）は使わない。入口は直近48hの出来事、最後の段落は AI をどう使うと効くかの向きで閉じる（v7.2）。

### 引用型（夕の代替）— 「Jevが遂にwaitlist無しで全員に解放」11万表示の型
60〜130字。1行目で何が起きたか、2行目で一言（「誰でも試せるので是非！！」「これ普通に現場で使えるやつ」）。英語の引用元は解説の段落を足して200字まで可（v7.2）。

### 口調
- です・ますとタメ口を混ぜる。「、、」「！！」「笑」OK
- 感想は短く素直に（「普通に欲しい」「これは嬉しい」「想像以上に完成度高い」）
- 一人称は僕
- 段落ごとに空行

### 残す禁止
- 創作（未実施の体験・未確認の数字）。作ってみたは本当に作ったものだけ
- ハッシュタグ、本文へのURL（URLは自己リプ）、DM誘導
- 客先名・客先図面・受託案件の中身
- 競合サービスの紹介（下の節）
- 攻撃・炎上狙いの煽り。【警告】は公式発言の切り出しなど事実がある時だけ

## 選び方（5観点・各0〜2点・7点以上で採用）
1. 驚き：映像を見た瞬間に「すげー」となるか（解説が要るものは0）
2. 絵：動画（2）／画像（1）／文字だけ（0）
3. 鮮度：24h以内（2）／48h以内（1）
4. 建設との距離：建設現場・設計・積算そのもの（2）／建設に一言でつながる（1）
5. 確かさ：公式・当事者の発表や本人投稿（2）／二次報道（1）
朝枠は4を「AIの大ネタ度」と読み替える。
**足切り（v7.1）**：朝・昼・夜・土曜のニュース枠は、2の絵が2点（動画・GIF・デモ映像を video_url で付けられる）でなければ合計点に関係なく不採用。

### 本質投稿（夕枠）の5観点（各0〜2点・8点以上で採用）
1. 主張：1行目で1つに言い切っているか（両論併記・〜な気がする は0）
2. 仕組み：なぜそうなるかを建設業の仕組みで説明しているか
3. 具体：公開の数字・時事・工種や書類名など、現場の具体が1つ以上あるか
4. 建設固有：建設業を知らないと書けない一文があるか（AIアカウントでも書ける内容は0）
5. 判断：読んだ人の明日の判断が1つ変わるか
足切り（点数に関係なく不採用）：入口が直近48hの出来事でない／締めが AI を後回しにする向き（v7.2）
editorial の scores はこの5つのキー（claim / mechanism / concrete / construction_only / decision）で入れる。8点未満なら引用に切り替える。

- 一次ソースで日付・数字を確認してから書く。原文にない数字は書かない

## 画像・動画・出典
- 動画がある投稿は video_url（https://x.com/<user>/status/<id>/video/1）を付け、画像は付けない。無断の再アップロードはしない
- ニュース枠（朝・昼・夜・土曜）は動画必須。画像だけのネタは出さない（v7.1）。本質投稿は画像なし（image_type='none'）
- ニュースサイトのスクショは使わない
- 出典は自己リプの「■ 出典」

## 競合紹介の除外（2026-09-10 本人指示・継続）
建設業向けAI開発・導入支援、BPO、営業代行などツクノビと競合するサービスの紹介・推薦・引用・リプ・RT候補は採用しない。国内外とも対象。光/Hikari（燈）、ミャク楽（WIREBASE/itomaAI）、Motif は除外。海外の建設ロボット・重機・BIMのメーカー（Boston Dynamics、Built Robotics、Autodesk 等）は競合に当たらない。判断できないものは候補にしない。
