狙う反応は「これすげー」の一つだけ。説明で納得させるより、最初の3秒で絵で驚かせる。

## 柱は2本
1. **作ってみた**（週2〜3本・本人とローカルの Claude Code で制作。ルーティンは作らない）
   建設の業務をAIにやらせたデモ動画。「Claude Opus5.5 × ○○」「作ってみた」「やらせてみた」で出す。製品発表・リリース・受託案件としては出さない（「リリースしました」「できるようにしました」「サービス化」は書かない）。客先名・客先図面は出さない。図面は実務密度の自社作図か公開図面。
2. **海外の建設AIのすげーニュース**（ルーティンで毎日2本＝昼・夜）
   ロボット、自律で動く重機、3Dプリント住宅、BIM/CADを操作するAI、ドローン測量、現場の自動化など、映像を見て驚くもの。解説記事・調査レポート・市場予測・「〜の6つの領域」のような記事は採用しない。資金調達・出資・買収・合弁・提携のニュースも、金額が大きくても絵がないので採用しない（10-01 本人「面白くない」）。機械やAIが実際に動いている映像があり、何をしているか1秒で分かるものだけ。個人が作ってみたものの海外バズ（例：コードを書かずに作った設計ツール）も対象。

一般AIの速報（朝）と引用（夕）は脇役として残す。

## 型（チャエン @masahirochaen のバズ投稿をそのまま使う）
09-21〜27 の本投稿67本（imp中央値2.2万）の上位はほぼ次の型。

### 速報型（朝・昼・夜）— 24万/18万/10万表示の型
```
【速報】Googleが「Googlebook」を発表、本日から予約開始

Chromebookでも普通のノートPCでもない、Gemini前提の新カテゴリという打ち出し。

・2.8K OLEDタッチディスプレイ搭載
・バッテリー14時間駆動
・キーボードに専用のGeminiキー
・Androidスマホとシームレス連携、製造はHP

「今日は何を作る?」と話しかけて壁紙をその場で生成するデモ付き
↓詳細
```
1. 1行目：【速報】【超速報】【朗報】【注目】のどれか＋主語＋何をしたか。社名と製品名を入れる
2. 1〜2行の本音：「普通に欲しい」「これは嬉しすぎる」「現場で普通に使えそう」「これは待ってた人めちゃくちゃ多いはず」など短く素直に
3. ・箇条を3〜4つ。数字（何秒・何%・何台・何m²）を入れる
4. 締めは「↓詳細」
5. 動画を付ける（video_url）。自己リプに「■ 補足」（箇条で背景・条件）と「■ 出典」（URL）
200〜270字。建設ニュースは、日本の現場で何が変わるかを本音の行か補足に1行入れる。

### 作ってみた型 — ブクマ最多（577）の型
```
Opus 5.5でアニメも作れる、、、　これは結構使えるかも。

海外で話題になっていた「全フレームをJavaScriptで描画するアニメ」を、Claude Code × Opus 5.5で日本語版にしてみました。
（箇条4つ：何をやったか・どこまでAIか）
今回はcanvasで1,395フレームを描画してmp4化。レンダリングも約2分でした。
（使い道1行）
（一言）
```
1行目に驚きの一言（「Opus 5.5で○○もできる、、、」）→ 何を渡して何をさせたか → 箇条4つ → 作業の実数（図面の枚数・室数・時間）→ 使い道 → 一言。250〜380字。

### 引用型（夕）— 「Jevが遂にwaitlist無しで全員に解放」11万表示の型
60〜130字。1行目で何が起きたか、2行目で一言（「誰でも試せるので是非！！」「これ普通に現場で使えるやつ」）。

### 口調
- です・ますとタメ口を混ぜる。「、、」「！！」「笑」OK
- 感想は短く素直に（「普通に欲しい」「これは嬉しい」「想像以上に完成度高い」）
- 一人称は僕
- 段落ごとに空行

### 残す禁止
- 創作（未実施の体験・未確認の数字）。作ってみたは本当に作ったものだけ
- ハッシュタグ、本文へのURL（URLは自己リプ）、DM誘導
- 客先名・客先図面・受託案件の中身
- 競合サービスの紹介（下の節）
- 攻撃・炎上狙いの煽り。【警告】は公式発言の切り出しなど事実がある時だけ

## 選び方（5観点・各0〜2点・7点以上で採用）
1. 驚き：映像を見た瞬間に「すげー」となるか（解説が要るものは0）
2. 絵：動画（2）／画像（1）／文字だけ（0）
3. 鮮度：24h以内（2）／48h以内（1）
4. 建設との距離：建設現場・設計・積算そのもの（2）／建設に一言でつながる（1）
5. 確かさ：公式・当事者の発表や本人投稿（2）／二次報道（1）
朝枠は4を「AIの大ネタ度」と読み替える。

## ネタの取り方
- 海外の建設AI：X の動画付き投稿が主（output/slack_buzz.json と output/ai_buzz.json の「🌐」海外建設アカウント・英語検索。ConstructionDive / ENRnews / TheB1M / Procore / BentleySystems / Trimble / Autodesk ほか）。WebSearch で「construction robot」「autonomous excavator」「3D printed house」「AI construction site video」など英語で直近48hを追加検索する
- RSS（output/news_feed.json の construction_global）は補助。解説記事しかなければ採用しない
- 一次ソースで日付・数字を確認してから書く。原文にない数字は書かない

## 画像・動画・出典
- 動画がある投稿は video_url（https://x.com/<user>/status/<id>/video/1）を付け、画像は付けない。無断の再アップロードはしない
- 動画が無ければ公式ページの画像（image_type='screenshot'）。ニュースサイトのスクショは使わない
- 出典は自己リプの「■ 出典」

## 競合紹介の除外（2026-09-10 本人指示・継続）
建設業向けAI開発・導入支援、BPO、営業代行などツクノビと競合するサービスの紹介・推薦・引用・リプ・RT候補は採用しない。国内外とも対象。光/Hikari（燈）、ミャク楽（WIREBASE/itomaAI）、Motif は除外。海外の建設ロボット・重機・BIMのメーカー（Boston Dynamics、Built Robotics、Autodesk 等）は競合に当たらない。判断できないものは候補にしない。
